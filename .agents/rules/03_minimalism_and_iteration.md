# 03 — Minimalism & Fast Iteration

## Incremental Progress
1. **Start with a Working Minimal Baseline**: Build an end-to-end naive pipeline first (Agent -> Harness -> Score -> Submission zip).
2. **Measure First, Optimize Second**: Never introduce complex multi-agent architectures or fine-tuning without measuring baseline performance.
3. **Ablation Studies**: Test each prompt change or tool addition individually to measure its delta on the evaluation metric.
