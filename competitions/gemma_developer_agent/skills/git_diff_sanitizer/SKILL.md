# Git Diff Sanitizer Skill

## Objective
Sanitize code diffs generated by the patch drafter to eliminate unnecessary whitespace, remove temporary debug artifacts, and ensure 100% compliance with SWE-bench unified diff standards.

## Protocol
1. **Remove Ephemeral Artifacts**: Delete any temporary reproduction scripts or scratch logs before invoking `submit_patch()`.
2. **Review Modified Files**: Verify only source files directly addressing the issue are modified.
3. **Check Formatting**: Ensure strict compliance with project linters (`black`, `flake8`, `isort`) without modifying unrelated lines.
4. **Unified Diff Generation**: Generate unified diff with `git diff -U3` and confirm no unintended trailing spaces or corrupt patch hunks.
